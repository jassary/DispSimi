LABORATORIO TÉRMICO
Termodinámica en la computadora

1. Extrae todo el ZIP con «Extraer todo».
2. Abre la carpeta Laboratorio Termico.
3. Haz doble clic en Laboratorio Termico.exe.
4. Elige un escenario y pulsa Ejecutar.

Versión para Windows de 64 bits (x64). Python y Tcl/Tk vienen en la carpeta
runtime. Conserva juntas las carpetas runtime y Codigo fuente y el ejecutable.

En Codigo fuente están el simulador, el lanzador, las pruebas y la guía de uso.
